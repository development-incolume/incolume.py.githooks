# incolume.py.githooks

**Hooks git para projetos incolume**, distribuídos como fonte de hooks
[pre-commit] para os projetos consumidores.

## O que é

Um conjunto de hooks que padroniza o ciclo de contribuição: validação de
mensagem de commit (Conventional Commits), nomes de branch e de arquivo,
detecção de chaves privadas, rodapés de commit e mensagens de esforço
pós-commit.
